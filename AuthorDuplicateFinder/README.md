# 📚 AuthorDuplicateFinder (폴더 간 작가명 중복 검색기)

서로 다른 두 개의 폴더 내에 저장된 파일들의 파일명 규칙(`[작가명]...`)에 기반하여 작가명을 정규표현식으로 자동 추출하고, 두 폴더 간 겹치는(중복) 작가 및 매칭 파일 목록을 한눈에 비교 분석하며 CSV/Excel로 추출하는 파이썬 데스크톱 프로그램입니다.

---

## 📌 주요 기능 사양

1. **정규표현식 기반 작가명 파싱 (`^\[(.*?)\]`)**:
   - 파일명 시작 부분의 대괄호 `[작가명]`을 자동 정밀 파싱합니다.
   - 예시: `[홍길동] 구운몽.txt` ➔ 작가명: **홍길동**

2. **재귀적 하위 폴더 스캔 옵션**:
   - 체크박스 선택 하나로 선택 폴더의 전체 하위 디렉토리까지 재귀 탐색 스캔이 가능합니다.

3. **결과 내 검색 및 컬럼별 정렬**:
   - 추출된 중복 작가명, 폴더 A 파일 개수, 폴더 B 파일 개수별 클릭 정렬(`Sorting`) 지원.
   - 실시간 결과 내 검색어 필터링 지원.

4. **더블 클릭 상세 보기 & 윈도우 탐색기 바로가기**:
   - 결과 목록 항목 더블 클릭 시 선택 작가의 파일 전체 경로 목록 및 **'선택 파일 탐색기에서 위치 열기'** 기능 제공.

5. **Excel 완벽 호환 UTF-8 BOM CSV 내보내기**:
   - `utf-8-sig` 인코딩을 적용하여 엑셀에서 파일을 열었을 때 한글 깨짐 없이 정갈한 표 형태로 즉시 열립니다.

## 🚀 실행 방법

### 방법 1: 배치 파일 실행 (추천)
`AuthorDuplicateFinder` 폴더 내의 **`run_app.bat`** 파일을 더블 클릭하여 즉시 실행합니다.

### 방법 2: 파이썬 직접 실행
```bash
python app_gui.py
```
